# 📝 ShreeTodo

A responsive **Todo List application** built with React and Tailwind CSS, designed to help users manage tasks with a clean and simple user interface.

## ✨ Features

- 📝 Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 📱 Responsive design
- 🎨 Clean and simple user interface

## 🛠️ Technologies Used

- React
- Tailwind CSS
- JavaScript
- Vite
